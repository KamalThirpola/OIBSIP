# OIBSIP – Java Development Projects

This repository contains Java development tasks completed for the OASIS INFOBYTE internship.

## Task 1: Online Reservation System

A Java Swing desktop application with user registration/login, train reservation, PNR generation, booking history and ticket cancellation. It uses JDBC with a local SQLite database.

- [Open Task 1 project folder](./Java%20Development-Task%201-Online%20Reservation%20System/)
- [Task 1 README and setup instructions](./Java%20Development-Task%201-Online%20Reservation%20System/README.md)

## Technology

- Java 17+
- Swing GUI
- JDBC
- SQLite
- Maven

**Note:** This is an educational demonstration and is not connected to IRCTC or a live railway reservation service.
